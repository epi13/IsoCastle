# Visual Overhaul Evidence

This directory retains representative evidence for the original IsoCastle visual overhaul. The images are direct browser captures of deterministic game state, not mockups.

`before/1600x900.png` shows the fixed-origin, downscaled world and clipped objective at the primary acceptance resolution. `before/3440x1440.png` additionally shows the old 16:9 pillarboxing behavior on an ultrawide viewport. `before/metrics.json` records browser viewport, canvas CSS, backing-store, document-scroll, and console-error measurements for all six required desktop resolutions.

Final representative captures will live under `after/`. Transient full-resolution matrices and traces remain under ignored `artifacts/`.
